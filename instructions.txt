Flipclock app runs in windows
Initial ideas:
- Format: 24h HH:mm:ss => the two seconds tiles must be resizable as one could opt to make them smaller, and not bigger than the other minutes/hours tiles.
- The tiles are 3d elements realistically rendered, with real lighting/shadowing for a more inmersive experience.
- 3d effect flipling the numbers, with realistic rendering ilumintaion 
- The colors of the tiles, and the numbers can be customizable and saved
- You can select a background image that stands behind the tiles of the clock with shadowing
- It must shows also the day of week and the date in italian  in the format : Giovedì, 15 Ottobre 2026. This info can be placed in three different places: bottom left, bottom right, bottom center.
- The whole clock must resize as the window it lives in get resized. 
- On every tile change, a "tick" sounds. This can be switched on/off in the config panel. The sound can also be customizable selecting an .mp3 file from the system.
- The clock will take the whole windows size with only 250px of margin. This can also be customizable.
- The font used in the application (for numbers and text) can be customizable, getting the fonts installed in the system.
- All the customizable options must appear in a panel when a cog button get clicked. The cog button is in the top right corner of the screen.
- All the customizable options must be saved in a file so the next time the app runs get the last state. The format of this file will be .TOML
- Developed in .net


- some ideas of the layout can be found in http://flipclock.online
